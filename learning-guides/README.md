## 学習方針

- Phase 1の既存1〜12段階の順序は変更しない。
- 既存実装を作り直すのではなく、Testや補足学習を既存の流れに追加する。
- Phase 2以降も同じIssue Trackerを継続的に拡張する。
- 各Topicは「実装 → Test → Failure再現 → 測定 → Trade-off説明」の順で学ぶ。
- AIが生成したCodeをそのまま採用せず、動作原理とFailure条件を自分で検証する。
